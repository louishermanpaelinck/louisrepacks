Help & Instructions

Everything you need to know to download and install the repacks correctly.

1. How to download

  1. Go to the game page and click Download Now.
  2. You will be redirected to Mega.nz (or another host).
  3. Click the download button on the host site and wait until the file is fully downloaded.
Tip: Use a download manager (like JDownloader or Free Download Manager) for more stable downloads.

2. Opening the RAR files

All repacks are compressed as .RAR files to keep the size as small as possible. To open these files you need a program that can extract RAR archives.

We recommend using WinRAR (Windows) or 7-Zip.

Recommended:

Download WinRAR Download 7-Zip
After installing WinRAR or 7-Zip, just right-click the .RAR file → Extract Here or Extract to…

3. How to install the game

  1. Extract the RAR file using WinRAR or 7-Zip.
  2. Open the extracted folder.
  3. Run the Setup.exe (or the installer that is inside).
  4. Follow the installation steps.
  5. When the installation is finished, start the game from the shortcut or the install folder.

4. Common problems

  • Missing DLL / Error on launch → Install the latest Visual C++ Redistributables and DirectX.
  • Antivirus deletes files → Add an exception for the game folder (false positive is common with repacks).
  • Game doesn't start → Run as Administrator or try compatibility mode (Windows 7 / 8).
  • RAR file is corrupted → Re-download the file completely.

5. Need more help?

If something still doesn't work, make sure you followed all steps above. Most issues are solved by using WinRAR and extracting the files correctly.
